# The built-in web browser

The Web button in the toolbar opens a small browser in place of the
Preview and Live panes: back, forward, home, reload, and an address bar
that also searches (type words and it searches the web; type a web
address and it goes there). It needs the desktop app.

**Go Live** sends exactly what the page shows to the live output, as it
moves: video, animation and scrolling all come through, at about 20
frames a second. The projector draws the pictures; it never loads the
page itself. The page is shown at 16:9, the shape of the screen, so what
is on the operator's page is what the room sees. The Live button in the
toolbar blinks while it is on screen.

It stops when you press **Stop Live**, **Clear**, close the browser, or
put anything else live (words, Black, Logo).

Notes:

- Sound plays on the operator's computer, not through the projector
  window. Put the page's audio on the same output as the room if you
  need it.
- Pages open with no access to the app: no Node, no preload script,
  http and https only, and a link that wants a new window opens in the
  same view. Browsing data is kept in its own store, apart from the app.
- Showing a web page in church is the operator's call: check that you
  have the right to display what you show.
