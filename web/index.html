01

Plan it, preview it, send it live.

The schedule runs down the left. The slides of the selected item sit in the Preview pane, and what the congregation sees sits in the Live pane beside it. Nothing reaches the screen until you decide.

  • Drag songs and verses from the library into the schedule
  • Every slide labelled, with a thumbnail you can click
  • Logo, Black and Clear cut the screen in one click
02

A song editor that thinks in blocks.

Type a verse, name it, add a chorus. The words list on the left, the slide as it will look on the right, with a zoom slider to check the fit. Paste a whole song and it splits itself into blocks.

  • Words, Slides and Masters tabs
  • Your library is saved on this computer until you delete a song
  • Import from EasyWorship, OpenSong and OpenLyrics
03

Scripture in one box.

Type "John 3 16" and the Bible jumps there. Press Enter to preview, Enter again to go live, then step with the arrow keys. Long passages shrink to fit the screen and short ones grow.

  • Eighteen public domain Bibles, downloaded once and kept offline
  • Up and Down move through verses while live
  • Pick a verse in the schedule and it is highlighted in the table below
04

Backgrounds, layouts and light.

Photos and motion backgrounds in small grids, six layouts from fullscreen to subtitles, and text that stays readable on all of them.

  • Photo, motion and classic backgrounds, plus your own
  • Lower third and subtitle layouts for video streams
  • Slide font is per theme, Calibri and Arial first
Motion backgrounds

Slow light behind the words.

Looping videos and still photos ship with the app, each small enough to run on an older church laptop. Add your own in one click.

Moving over

Bring your whole Sunday with you.

Move a whole Sunday over in one afternoon, and verify the move before Sunday, not during it.

Import is under active work: the formats here are covered, and full fidelity EasyWorship library import is being finished against real sample files.

  • EasyWorship schedules

    Import .ews schedule files, which are ZIP archives, and read the schedule structure directly.

  • EasyWorship song libraries

    Import song databases including Songs.db and SongWords.dat, following the documented open source importer path.

  • OpenSong and OpenLyrics

    Import OpenSong and OpenLyrics song files, so churches coming from any free tool are covered too.

  • Open export

    Songs, schedules and themes export to open files, so nobody is ever locked in again.

Community Songbook

The feature no free tool owns yet.

Churches contribute and correct lyrics, and updates sync to everyone. This matters most for Nigerian songs, which no shared library covers well today.

The Songbook tab is already in the app. The sync service is the next phase of work.

  • Edits sync to everyone

    A church fixes a line, adds a verse or adds a translation, and the edit reaches the shared library as a new version.

  • Full version history

    Every song keeps its history, so a bad edit can be rolled back in one click.

  • Moderation

    New songs and edits from new contributors sit in a review queue until trusted editors approve them, and any user can report a wrong or copyrighted lyric.

  • Contributor credit

    Every song shows its contributors and source church, so the community, not an anonymous database, gets the credit.

  • Copyright guardrails

    Contributors confirm they own the lyric, it is public domain, or they have permission to share it. A CCLI number field lets licensed churches record the licence. Modern commercial songs without permission are refused.

  • Offline first

    Every church keeps a full local copy. Sync happens when there is internet, and a service never depends on it.

Content and licensing

Only what the licence allows, always labelled.

Every song and Bible carries a source field: public domain, owned, licensed or community. Copyrighted material is never bundled without permission or a licence.

  • Bibles, offline

    Eighteen public domain Bibles are one click away, from the King James and American Standard to the Berean Standard, Geneva and Clementine Vulgate. Add the ones you want and each is downloaded once, then works with no internet.

  • Nigerian languages

    Downloadable packs from eBible.org include Yoruba, Hausa, Igbo, Nigerian Pidgin, Fulfulde and other Nigerian languages. Each translation ships with its own licence note, and the app only bundles what the licence allows.

  • Bring your own translation

    CrossWire SWORD modules can be imported, so churches can use translations they already own.

  • Copyrighted versions

    Versions like NIV, ESV, NKJV, NLT and NASB are never bundled or redistributed. They stay reachable only through a licensed lookup route, under those services own terms.

  • Hymns

    The seed library is public domain hymns, each text stating its public domain status. As a rule, copyright generally expires 70 years after the writer's death. Anything newer needs permission or a licence.

  • The legal route for modern songs

    For copyrighted lyrics, paste your own lyrics or import through a CCLI SongSelect licence. That is the legal route for licensed churches.

Get it

Run it from source today.

Installers for Windows, Linux and macOS are the final release phase. Until then, the app runs from source in a few commands.

$ git clone https://github.com/toluwanibakare/true-worship.git
$ cd true-worship
$ npm install
$ npm run backgrounds   # generate the built-in set, once after cloning
$ npm run build         # typecheck + production build
$ npm run electron      # run the built desktop app

For development, npm run electron:dev runs the full desktop app with operator and projector windows, and npm run dev runs the frontend in a browser for UI work only.

FAQ

Questions churches ask.

Is True Worship really free?

Yes. It is free and open source under GPL-3.0. There is no subscription, no trial and no paid tier today.

Which platforms does it run on?

Windows, Linux and macOS, from one codebase. The operator window runs on the laptop and the live output window goes to the projector.

Does it work without internet?

Yes. Songs, Bibles, schedules and themes live on disk. Bibles you download keep working offline. Online lookups and songbook sync are extras, never requirements for a service.

Can we move from EasyWorship?

That is the plan. Import covers .ews schedules, song databases, OpenSong and OpenLyrics files, with full fidelity library import being finished against real sample files. Everything also exports to open files.

What about copyrighted songs and Bibles?

Only public domain, owned or licensed content is bundled, and every item is labelled with its source. Modern songs need permission or a CCLI SongSelect licence, and copyrighted Bible versions are never bundled.

Will it have Nigerian language Bibles?

Yes, through downloadable eBible.org packs including Yoruba, Hausa, Igbo, Nigerian Pidgin and Fulfulde, each with its own licence note.

When do installers arrive?

Installers for Windows, Linux and macOS are the final release phase, along with docs and the first public launch to Nigerian churches. Until then, run from source with the commands above.

Ready to run your next service on it?

Free and open source, on Windows, Linux and macOS. Get the source and run it from the commands above.
